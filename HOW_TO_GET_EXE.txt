ROCKY RAW STUDIO - WINDOWS EXE (NO PYTHON ON END USER COMPUTER)

OPTION A - BUILD ONLINE (NO PYTHON INSTALLATION)
1. Sign in to GitHub and create a PRIVATE repository.
2. Upload the files and folders in this ZIP to the root of that repository,
   including the hidden .github/workflows/build-windows-exe.yml file.
3. Open the GitHub repository's Actions tab.
4. Select "Build Rocky RAW Studio Windows EXE".
5. Click "Run workflow" then wait for the run to finish.
6. Open the completed run; under Artifacts download Rocky_RAW_Studio_Windows_EXE.
7. Extract the downloaded ZIP. Run Rocky_RAW_Studio.exe on Windows.
   Python is NOT needed on the computer running the finished EXE.

OPTION B - BUILD LOCALLY (REQUIRES PYTHON ON BUILD PC ONLY)
1. Install Python 3.10+ with PATH enabled.
2. Double-click BUILD_WINDOWS_EXE.bat.
3. Find dist\Rocky_RAW_Studio.exe.

The EXE opens the HTML-based UI in your default browser and runs a local
127.0.0.1 backend. This is local software, not an uploaded/cloud app.
Keep the program running while working. Folder browsing uses native Windows
dialogs; the browser presents the interface.

The EXE has not been built or Windows-tested in this environment.
